Sécurité et confidentialité

Radar roches s'installe sans passer par le Play Store. Voici ce qui permet de lui faire confiance, et comment le vérifier soi-même.

En bref

  • ✓ Code source public : tout ce que fait l'appli peut être lu.
  • ✓ Construite automatiquement par GitHub à partir de ce code, jamais sur un ordinateur personnel.
  • ✓ Toujours signée avec la même clé : personne ne peut faire passer une fausse mise à jour.
  • ✓ Analysée par plus de 70 antivirus (VirusTotal).
  • ✓ Aucune collecte de données : pas de compte, pas de statistiques, pas de publicité.
  • ✓ Gratuite, sans achat intégré.

Le code est public

Le code de l'appli, du site et des outils de préparation des données est sur GitHub : github.com/YMCA-dev-wow/radar-roches. Chaque version de l'appli y est construite automatiquement, à partir du code publié : on peut remonter de chaque APK à la modification qui l'a produite.

La signature

Chaque version est signée avec la même clé. Android refuse d'installer une mise à jour signée par une autre clé : une APK modifiée ou contrefaite ne peut pas remplacer la vraie. Empreinte du certificat (SHA-256) :

1A:DC:BA:45:6F:08:76:2E:DC:44:5F:16:46:63:CA:A7:00:D7:34:06:05:E8:1F:FE:8D:95:72:CD:4A:86:36:BA

Les autorisations demandées

AutorisationPourquoi
Position, y compris en arrière-planLe radar suit ta position pour détecter les roches sur ta route, écran éteint.
NotificationsRelais des alertes sur la montre, annonce des mises à jour, radar actif.
InternetTélécharger le relief des zones, les marées en direct, les fonds de carte, les mises à jour.
Maintien en éveil, batterieEmpêcher Android d'endormir le radar pendant la séance.
Réglage du volumePousser le volume des alertes pendant la séance, puis le rétablir.

L'appli ne demande ni contacts, ni photos, ni micro, ni appareil photo, ni SMS, ni appels.

Tes données

  • Rien n'est collecté : pas de compte, pas d'identifiant, pas de mesure d'audience, pas de publicité.
  • Tes positions, tes séances et leurs journaux restent sur ton téléphone. Ils n'en sortent que si tu envoies toi-même un journal (Plus → Avancé → Journaux de session → Envoyer).
  • Le partage de roches est volontaire : seules les roches que tu choisis de partager sont envoyées, avec le nom que tu indiques.
  • Comme toute appli connectée, l'appli contacte quelques services pour fonctionner : le site de l'appli (relief, mises à jour), le Shom (marégraphes) et les fournisseurs de fonds de carte (IGN, Shom, OpenStreetMap). Ces services voient l'adresse réseau du téléphone, comme pour la visite d'un site web.

L'avertissement « appli inconnue »

À l'installation, Android (Play Protect) prévient que l'appli ne vient pas du Play Store. Ce message s'affiche pour toute appli installée en dehors du Play Store : il ne signale pas un danger. Les points ci-dessus permettent de vérifier l'appli par d'autres moyens.

Vérifier soi-même (pour les curieux)

  • Comparer l'empreinte SHA-256 du fichier téléchargé avec celle de la version ci-dessus.
  • Contrôler le certificat avec les outils Android : apksigner verify --print-certs radar-roches.apk.
  • Consulter le rapport VirusTotal de la version (lien ci-dessus).
